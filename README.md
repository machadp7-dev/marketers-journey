# marketers-journey

`index.html` is a standalone site, ready for GitHub Pages.

Before publishing, review the page for sensitive content. It currently says
"Confidential, internal use only"; a GitHub Pages site may be publicly accessible.

To publish, push `index.html` to `main`, then in the repository open **Settings > Pages**.
Under **Build and deployment**, choose **Deploy from a branch**, select `main` and
`/(root)`, then save. The site URL will be:

https://machadp7-dev.github.io/marketers-journey/
